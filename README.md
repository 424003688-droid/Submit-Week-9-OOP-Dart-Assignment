# PC16 Week 9: OOP in Dart (Part 1)

Console-based Dart program demonstrating core Object-Oriented Programming principles.

## Features
- **Class Definition**: Properties and behaviors modeled after a real-world object.
- **Constructor**: Initializes object fields during creation.
- **Encapsulation**: Protects sensitive internal state using private variables (`_`).
- **Collections**: Data organized using List and Map structures.
